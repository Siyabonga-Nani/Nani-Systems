# Nani Systems Build Plan

## Phase Separation Rule
Every phase must clearly distinguish:
**WHAT** the business/product requires
from
**HOW** the technology will implement it.

Do not pull technical implementation decisions forward into earlier phases. For example, Phase 0 defines that a pricing engine exists and that customers can configure projects, but Phase 4 determines exactly *how* that engine works technically.

## Required Build Process
The project will follow this strict sequence:
**PLAN → BUILD → REPORT → REVIEW → TEST → APPROVE → NEXT PHASE**

Development and the AI agent (Antigravity) must stop after the approved task/phase. Do not autonomously continue into another phase.

## Development Roadmap

### PHASE 0: Commercial & Product Definition
Establish the approved business/product source of truth, business rules, and service models before further development begins. *(Current Phase)*

### PHASE 1: Project Foundation & Local Development Environment
Set up the core project structure, frameworks, and local development tools.

### PHASE 2: Database & Backend Foundation
Establish the core data architecture, database setup, and initial backend systems.

### PHASE 3: Public Website & Brand Experience
Develop the public-facing platform to present Nani Systems' identity, services, and pricing.

### PHASE 4: Services, Pricing & Project Configuration
Implement the technical mechanics for the service catalogue, feature selector, and pricing engine.

### PHASE 5: Lead / Project Request System
Develop the system for customers to submit ideas, requirements, and request quotations.

### PHASE 6: Admin Operations Dashboard
Build the internal dashboard for operational management of customers, projects, and leads.

### PHASE 7: Quotes, Contracts & Project Workflow
Implement the workflows for quoting, generating contracts, handling milestone schedules, and processing payments.

### PHASE 8: Subscriptions, Maintenance & Client Management
Develop systems to manage ongoing services, hosting, maintenance, and long-term client engagements.

### PHASE 9: Notifications & Operational Communications
Build the notification engine for emails, alerts, and system communications.

### PHASE 10: Security, Testing & Production Readiness
Conduct full security reviews, automated testing, and prepare the system for the production environment.

### PHASE 11: Full System Verification & Launch Candidate
Perform end-to-end platform verification to produce a founder-approved launch candidate.

### PHASE 12: Production Deployment / Hosting
Deploy the Nani Systems platform to live production infrastructure.
